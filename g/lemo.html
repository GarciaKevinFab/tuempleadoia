Guía Lemo-Opuscar: videos animados gratis para tu negocio

Instala la skill gratis Lemo-Opuscar en Claude Code y crea videos animados solo con código en minutos.

Para quién es: Dueños de bodegas, tiendas o restaurantes en Perú que quieren videos promocionales personalizados sin programar.
Tiempo: 15-25 minutos · Costo: Gratis (Claude Code desde US$ 20 al mes, revisa el precio actual)

Paso a paso

  1. Instala Claude CodeDescarga Claude Code desde el sitio oficial de Anthropic. Abre la terminal de tu computadora.
  2. Agrega el marketplaceCopia y pega en la terminal: claude plugin marketplace add lemomo-ai/lemo-opuscar. Presiona Enter.
  3. Instala la skill Lemo-OpuscarEjecuta: claude plugin install lemo-opuscar@lemolab. Espera a que descargue los 99 estilos.
  4. Elige un estiloAbre la galería en lemomo-ai.github.io/lemo-opuscar. Elige uno como Watercolor o Pizarra para tu video.
  5. Pide el video a ClaudeEn Claude Code escribe el prompt con tu historia. El agente dibuja, narra y mezcla todo con código.
  6. Revisa y exporta el videoEl video se genera en segundos en tu carpeta. Revisa el resultado y guárdalo listo para usar.

Ejemplo listo para copiar

Haz un video de 30 segundos en estilo acuarela sobre los productos frescos de mi bodega 'La Esquina' en Lima. Incluye nuestro logo en rojo y blanco, colores peruanos y narra con voz cálida femenina: 'En La Esquina encuentras lo mejor de Perú cada día'.

Errores comunes

  • No instalar la skill correctamente: ejecuta los dos comandos exactos y reinicia Claude Code si falla.
  • Usar estilos sin ver el demo: revisa primero el video de ejemplo en la galería para elegir bien.
  • Olvidar poner /effort high: escribe /effort high antes de pedir el video para mejores resultados.
